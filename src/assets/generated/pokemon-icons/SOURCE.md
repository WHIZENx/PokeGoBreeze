# Pokémon table icon sheet

`pokemonicons-sheet.png` and `pokemon-icon-index.json` are generated vendor files. Run
`npm run update:pokemon-icon-sheet` to refresh both files together.

- Sheet: Pokémon Showdown's published `pokemonicons-sheet.png`
- Form indexes: `BattlePokemonIconIndexes` from the Pokémon Showdown client
- Cell size: 40 × 30 pixels, 12 columns

The source URLs and SHA-256 checksums captured during the update are stored in the
generated manifest. Pokémon names and images remain the property of their respective
rights holders. Review the upstream [smogon/sprites](https://github.com/smogon/sprites)
repository before redistributing these assets.
